# License Decision — Pending Owner Confirmation

The proposed license for core source code and SDKs is **Apache License 2.0** because it is permissive and includes an explicit patent grant. This is a recommendation, not an adopted legal decision.

Before publishing source code under an open-source license, the project owner must confirm:

- Copyright holder/contributor attribution.
- Whether all initial contributions can legally be licensed.
- Code license (recommended candidate: Apache-2.0).
- Documentation license (candidate: CC BY 4.0).
- Asset/sample-game licenses.
- Trademark and branding policy.
- Contributor License Agreement or Developer Certificate of Origin policy, if needed.

Do not claim the repository is legally licensed as Apache-2.0 until the canonical license text and ownership policy are added and confirmed.
